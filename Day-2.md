## Day-2 Checklist

- [Y] I understand what `PATH` is and why commands like `python` work without full paths
- [N] I can navigate the filesystem without clicking — using `cd`, `ls`, and `pwd` only
- [N] I can read, search, and inspect files using `cat`, `head`, `tail`, `grep`, and `wc`
- [N] I can edit a file using `nano` (open, edit, save, exit)
- [N] I understand pipes (`|`) and redirection (`>`, `>>`, `2>`) and can chain commands
- [N] I can set an environment variable in `.bashrc` and apply it with `source ~/.bashrc`
- [N] I know the difference between `export VAR=value` (available to child processes) and just `VAR=value` (shell-local)
